## 术语总结

　　以下是2.6、2.7供第二章章末合并的术语条目，不是完整第二章术语表。位置栏只记录这两节中的解释位置；全章首次出现位置由统稿人阅读完整正文后填写。章末表不能替代正文首次出现时的解释。

| 中文术语 | 英文或缩写 | 简明解释 | 本次正文解释位置 |
| --- | --- | --- | --- |
| 计算图 | Computational graph | 按数据依赖连接起来的计算表示，可用来追踪输入如何变成输出 | 2.6.1 |
| 节点与边 | Node / edge | 节点表示一次计算，边表示计算之间的数据传递关系 | 2.6.1 |
| 初始化张量 | Initializer | ONNX图中预先保存的命名张量，常用于保存权重和偏置，也可保存其他常量 | 2.6.1 |
| 中间张量 | Intermediate tensor | 执行模型过程中产生的数据，例如卷积得到的特征图 | 2.6.1 |
| 卷积 | Convolution / Conv | 用滤波器对局部输入加权求和并加偏置，沿空间位置重复计算以产生特征图 | 2.6.1、2.6.2 |
| 线性整流激活 | ReLU | 对每个元素取其与零的较大值，不改变张量形状 | 2.6.2 |
| 最大池化 | Max pooling / MaxPool | 在局部区域中取最大值，本例用于缩小特征图的空间尺寸 | 2.6.2 |
| 展平 | Flatten | 合并指定维度，本例保留批次维，将每张图片的特征排成一行 | 2.6.2 |
| 重塑形状 | Reshape | 改变张量形状但保留元素数量，本例导出图用它表达展平 | 2.6.3 |
| 全连接层 | Fully connected layer / Linear | 每个输出由输入特征的加权和加偏置得到 | 2.6.2、2.6.3 |
| 矩阵乘加 | Gemm | 支持转置及缩放的矩阵乘加算子，本例用于表达全连接层 | 2.6.3 |
| 随机失活 | Dropout | 训练时随机丢弃部分特征，本例在评估模式下直接传递输入 | 2.6.3、2.7.1 |
| 对数概率 | Log probability | 概率取对数后的值，本模型由LogSoftmax产生10类对数概率 | 2.6.2、2.7.2 |
| 张量布局 | NCHW / NHWC | 约定批次、通道、高和宽的维度顺序；二者不能仅靠改形状标签互换 | 2.6.2、2.6.5 |
| 固定形状 | Static shape | 各维度已经确定的形状，本例输入固定为[1,1,28,28] | 2.6.5 |
| 动态维度 | Dynamic dimension | 可在模型和工具允许的约束内变化的维度，不表示支持任意尺寸 | 2.6.5、2.7.3 |
| 算子集版本 | Opset | 规定一个算子域内采用哪组算子版本规则，不等同于PyTorch或IR版本 | 2.6.5、2.7.3 |
| 中间表示 | Intermediate representation / IR | 描述模型图及相关数据的表示形式，其版本与opset分别记录 | 2.6.5 |
| 评估模式 | Evaluation mode / eval | 切换相关层的推理行为，不等同于关闭梯度记录 | 2.7.1 |
| 样例输入 | Example input | 向导出器示范模型调用所需的张量，零样例不能用于判断识别效果 | 2.7.2 |
| 数值回归 | Numerical regression check | 对同一输入比较转换前后的原始输出，按事先约定的容差判断一致性 | 2.7.5 |
| 绝对误差 | Absolute error | 对比值与参考值之差的绝对值 | 2.7.5 |
| 相对误差 | Relative error | 绝对误差除以参考值的绝对值；参考值为零时此定义不适用 | 2.7.5 |
| 常量折叠 | Constant folding | 在满足等价条件时预先计算只依赖常量的部分，减少运行时计算 | 2.7.6 |
| 派生模型 | Derived model | 由原模型经简化或其他变换得到的新版本，必须另存并重新验证 | 2.7.6 |
