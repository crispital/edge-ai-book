# 自有模型基线与轻量化动机

状态：项目 README 框架，当前仅黄章磊 4.1 范围；尚无度量代码或实测报告。

## 目的与对应章节

接收 [03-transfer-learning](../03-transfer-learning/README.md) 产出的自有模型，记录参数量、文件大小和 PC 推理耗时，对照 1.5 的资源约束形成基线报告与资源预算、压缩目标表。依据见 [个人 SPEC](../第一阶段/docs/SPEC.md)。

本作者不在初始化中实现 4.3—4.9 的压缩实验。公共度量与报告格式需与 4.2 对接，正式测量时引用其实际版本。

## 环境与依赖

待登记 PC 的 CPU、内存、操作系统、运行软件版本、线程设置及输入条件。模型与依赖尚未获得和验证；依赖文件在最小实现确认后添加。

## 目录

- src/：本作者基线度量的核心实现。
- scripts/：统计与计时入口。
- configs/：输入、设备和计时配置。
- samples/：必要的小样例或固定测试清单。
- expected_outputs/：真实统计结果和核对材料。
- docs/：计时边界、资源预算及与 4.2 的格式对应。
- README.md：运行入口和限制说明。

## 准备材料

固定模型版本及校验值、输入形状与数值精度、前后处理、固定样本及数据划分清单、环境记录、1.5 资源约束和 4.2 度量规范。模型存 .local/models，避免重复复制或重新训练后仍称同一基线。

## 操作与运行命令

待实现、实际运行后补充：统计参数量 → 记录指定模型格式的文件大小 → 按明确计时范围、预热和重复次数测 PC 耗时 → 形成报告。

当前没有可执行命令，不使用示例数字充当实测。

## 输出与核对

正式产出保存在 reports/ch04：基线度量报告、资源预算与压缩目标表。性能数字记录设备、模型、输入尺寸、精度、软件版本、计时范围和日期。

预算及阈值尚未确定时写明未确定，不为了建立轻量化动机而假设模型已超限。PC 实测只支持对应 PC 条件；压缩后板端收益由后续平台实测确认。
