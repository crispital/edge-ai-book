## 在新电脑取得材料

新克隆使用main分支。已有克隆先确认自己的本地修改已妥善保存，再执行：

```powershell
git fetch origin
git switch main
git pull --ff-only origin main
```

仅做文稿审阅时可直接打开上述Markdown及配图。执行代码时按opset 17配套说明准备对应依赖。
