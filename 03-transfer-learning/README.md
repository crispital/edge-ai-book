## 目录

- src/：数据读取、模型适配及其他核心实现。
- scripts/：训练、导出、运行和验证入口。
- configs/：可共享配置；本机私有路径保存在 .local。
- samples/：许可明确、体积可控的小样例。
- expected_outputs/：固定样本的真实参考输出。
- docs/：数据与模型接口、限制、交接说明。
- README.md：唯一运行入口说明；环境文件在确定后增加。

目录当前只含占位，不代表这些功能已实现。
