## 2.6 计算图、算子与模型结构

### 本节解决的问题

读者已经能运行模型，但还需要回答：模型由哪些算子组成，张量形状怎样变化，权重位于哪里，以及这些结构为什么会影响后续导出和部署。

### 必须讲

1. 模型、计算图、节点、张量、权重、输入和输出之间的关系。
2. MNIST模型中的卷积、激活、池化、展平与全连接算子。
3. 形状沿计算图的变化，以及 batch、通道、高、宽的含义。
4. 静态形状、动态维度、NCHW/NHWC和算子版本对部署接口的影响。
5. 使用实际模型结构或可视化图核对节点、输入输出和权重，不把示意图当作真实模型证据。

### 配套产出

- 带标注的模型结构图或计算图截图；
- 算子与张量形状对照表。

本节不展开训练过程、ONNX导出命令、ONNX Runtime推理和板端转换。

## 2.7 PyTorch 模型导出 ONNX

### 本节解决的问题

读者需要把已经训练好的 PyTorch 模型变成可交换的 ONNX 文件，并确认导出的模型在结构、接口和数值上仍与原模型一致。

### 必须讲

1. 导出前切换到评估模式，准备样例输入，确定输入输出名称和固定形状。
2. opset选择与动态维度设置如何受目标工具支持范围约束。
3. 执行导出后，检查模型结构、输入输出名称、shape和dtype。
4. 使用同一输入比较 PyTorch 与 ONNX 输出，记录预测类别和数值差异。
5. 保存权重、导出脚本、原始ONNX和派生版本；模型简化后重新执行结构、接口和数值检查。

### 配套产出

- 导出与检查脚本；
- 模型版本记录。

本节不重讲模型训练，不承担ONNX Runtime完整基线教程，也不声称某个硬件工具能够接受尚未实测的模型。
