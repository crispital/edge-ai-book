# MNIST模型基线与轻量化动机

个人范围：4.1。状态：工程README和配置骨架，尚无度量结果。
依据：[个人SPEC](../第一阶段/docs/SPEC.md)，任务见[当前入口](../docs/current-tasks.md)。

## 模型与目的
沿用[02-onnx-baseline](../02-onnx-baseline/README.md)的同一MNIST模型、2.8基线与2.9接口，展示参数量、指定格式文件大小和Windows PC CPU耗时；对照1.5资源约束形成基线报告、资源预算与压缩目标表。
MNIST是否需要压缩取决于预算和实测，不预设模型已超限。其他压缩方法由对应作者负责。

## 目录与环境
src/和scripts/按需接入4.2公共度量方法；configs/存配置；samples/和expected_outputs/放固定样本清单和真实输出；docs/说明预算与接口。
Windows CPU为PC参考，AutoDL Linux为前序训练侧。环境、线程、预热、次数和计时范围实际确定后登记；配置示例不代表运行成功。

## 准备与功能
1. 接收同一模型权重、ONNX、来源版本、校验值、固定输入、参考输出及2.9接口。
2. 按4.2口径统计参数量和明确格式的文件大小，测PC耗时；能直接用公共实现就直接使用，不强制增加包装脚本。
3. 结合前序MNIST评价记录和1.5实际预算，解释资源开销、精度保留要求与压缩目标。
4. 报告保存reports/ch04，供后续压缩及硬件实测对照。

运行命令和依赖待实现验证后补充，当前无可执行命令。未取得模型和预算时，结果明确待测，目标不填虚构阈值。
文件大小不等于峰值内存；PC耗时不等于板端耗时；三项不能直接证明功耗。详细度量教程在4.2，本节解释实际数字与工程意义。
